# RFC-001 — Platform dan Fondasi Data

## Metadata dan urutan

- Status: Diusulkan.
- Fitur yang dimiliki: **F54, F55, F61**.
- Kompleksitas: **Tinggi**.
- Prasyarat seluruh RFC terdahulu: tidak ada; ini awal rantai.
- Pendahulu langsung: tidak ada.
- Penerus langsung: **RFC-002 — Identitas, Sesi, dan RBAC**.
- RFC-002 baru boleh dimulai setelah Definition of Done RFC-001 lulus.
- RFC ini tidak memakai komponen RFC-002 atau RFC setelahnya.

## Keputusan dan sasaran

Migrasikan prototype ke **modular monolith dengan runtime transaksi Go 1.27.1** dan **Next.js sebagai presentation layer tipis**. PostgreSQL/Neon tetap satu-satunya persistence. Migrasi memakai **goose**; query typed memakai **sqlc** di atas **pgx/v5**. Pin versi target `RULES.md`, validasi environment saat startup proses API, sediakan skeleton test/CI, UI responsif, dan formatter Indonesia. Hasil wajib: stack target lolos compatibility spike; development, test/preview, dan production-demo terisolasi; migrasi terversi menjadi satu-satunya pembentuk skema; tidak ada runtime DDL, JSON persistence, hardcoded secret/password, seed-on-request, atau ID berbasis waktu. Prisma dan NextAuth **bukan** stack target.

## Ruang lingkup

- Runtime API Go 1.27.1, router `chi/v5`, driver `pgx/v5`, migrasi goose, kode query sqlc, logging `log/slog`.
- Presentation Next.js (upgrade kompatibilitas UI mengikuti RULES) hanya merender halaman dan memanggil API Go; dilarang menulis transaksi domain dari Server Action/Route Handler.
- Baseline tabel `users` untuk memindahkan persistence prototype tanpa menambah perilaku auth.
- Env typed di Go, pool pgx, repository, error envelope, correlation ID, health check.
- Skeleton `backend/` dan komponen UI dasar, locale `id-ID`, `go test`, Playwright, dan CI.
- Decision gate reset branch demo atau backfill user prototype.
- `DATABASE_URL` (pooled) untuk request; `DATABASE_URL_UNPOOLED` (direct) untuk migrasi.

## Non-scope

- Auth/RBAC baru (RFC-002), audit/analytics (RFC-003), dan organizer (RFC-004).
- Event, order, payment, ticket, check-in, dashboard, atau notifikasi.
- Pemilihan payment, storage, email, analytics, dan scheduler provider.
- Uang atau data nyata dan microservice.
- Menyelesaikan login produksi; prototype NextAuth boleh tetap hidup hanya sebagai UI lama sampai RFC-002.

## Gap kondisi saat ini

- Paket UI masih Next 14/React 18/TypeScript 5/Tailwind 3; backend Go belum menjadi runtime transaksi.
- `lib/db.ts` menjalankan `CREATE TABLE IF NOT EXISTS` pada request.
- `lib/users.ts` memakai raw SQL, `data/users.json`, hash sync, dan ID waktu.
- Akun demo/password tetap serta fallback `NEXTAUTH_SECRET` berada di source.
- Schema Prisma prototype tidak mempunyai migration aktif dan **tidak** boleh dilanjutkan sebagai SoT.
- Health check prototype memicu DDL dan membuka jenis storage/jumlah user.

## Arsitektur komponen tekstual

`Browser → Next.js (RSC/Client UI) → HTTP JSON ke Go API`. `chi handler → DTO validation → application service → domain → repository interface → sqlc/pgx → PostgreSQL`. `os.Getenv → platform/env schema → immutable config`; domain tidak membaca env. `request → correlation context → slog`; UI memakai Tailwind dan helper `id-ID`. Domain tidak mengimpor `net/http`, chi, pgx, Next.js, atau SDK provider.

## Aliran data tekstual

1. Proses `cmd/api` memvalidasi env dan fail-fast sebelum listen.
2. Request mendapat correlation ID dan input divalidasi pada boundary Go.
3. Service memanggil repository; pool pgx mengakses PostgreSQL.
4. DTO memilih kolom eksplisit; logger mencatat outcome/durasi tanpa PII/secret.
5. UI memformat integer Rupiah dan timestamp UTC dengan zona eksplisit.
6. Kegagalan database menjadi 503; tidak ada fallback file/memori.

## Perubahan model data/skema eksak

Migration goose `0001_platform_baseline.sql` membuat/mengadopsi:

### `users`

- `id TEXT PRIMARY KEY`; CUID baru, ID prototype dipertahankan saat backfill.
- `name VARCHAR(120) NOT NULL`.
- `username VARCHAR(40) NOT NULL`.
- `email VARCHAR(254) NOT NULL`.
- `password_hash TEXT NULL`.
- `role VARCHAR(20) NOT NULL DEFAULT 'USER'`.
- `google_id VARCHAR(255) NULL`.
- `created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`.
- Check `username = lower(username)`, `email = lower(email)`, `role IN ('USER','ADMIN')`.
- Unique indexes `users_username_key(username)`, `users_email_key(email)`.
- Unique partial index `users_google_id_key(google_id) WHERE google_id IS NOT NULL`.

sqlc memetakan kolom snake_case ke struct Go. Tabel `_prisma_migrations` tidak dipakai. Goose memakai tabel versinya sendiri. Tidak ada tabel domain lain. Migration tidak menghapus data: preflight memilih reset branch demo yang disetujui atau backfill deterministik.

## Environment

- Wajib API: `DATABASE_URL`, `DATABASE_URL_UNPOOLED`, `APP_ENV`, `API_ADDR`, `WEB_ORIGIN`, `SESSION_SECRET`.
- `APP_ENV`: `development|test|preview|production-demo`.
- UI Next.js: `NEXT_PUBLIC_API_BASE_URL` (origin API, tanpa secret).
- Google ID/secret berpasangan dicadangkan RFC-002; jangan diwajibkan pada RFC-001.
- Production-demo menolak localhost, secret <32 byte, dan database berpenanda dev/test.
- Nilai env tidak pernah dicetak.

## Endpoint

Semua path di bawah ini dilayani **proses Go**, bukan Route Handler Next.js.

### `GET /api/health`

- Auth publik; tanpa body/query; `Cache-Control: no-store`.
- 200: `{"status":"ok","checks":{"app":"ok","database":"ok"},"correlationId":"req_..."}`.
- 503: envelope `SERVICE_UNHEALTHY`; tanpa host, SQL, jumlah user, atau secret.

### `GET /api/meta`

- Auth publik; 200: `{"locale":"id-ID","currency":"IDR","environment":"production-demo","version":"<build-id>"}`.
- Tidak membuka provider, connection string, atau commit sensitif.

## State dan caching

- PostgreSQL source of truth; pgx pool hanya mempertahankan koneksi.
- Health `no-store`; meta boleh TTL 300 detik setelah stabil.
- React state lokal untuk UI sementara; tidak ada global client state.
- Data transaksional masa depan tidak boleh dicache sebagai source of truth.

## UI/UX

- Mobile-first pada 360/768/1024/1440 px tanpa overflow penghalang aksi.
- Komponen awal: Button, Input, FieldError, Alert, Container, SkipLink, LoadingState.
- Loading, empty, error, dan offline berbeda; label SANDBOX/UJI tersedia.
- Waktu selalu menyebut zona; backend menyimpan UTC.

## Kode error stabil

`CONFIG_INVALID`, `DATABASE_UNAVAILABLE`, `SERVICE_UNHEALTHY`, `VALIDATION_ERROR`, `INTERNAL_ERROR`. Envelope: `{"error":{"code","message","correlationId","fieldErrors"}}`; pesan Indonesia dan tanpa stack/SQL/secret.

## Logging dan monitoring

- slog JSON: timestamp, level, service, env, correlationId, route, outcome, durationMs.
- Redact password, cookie, authorization, OAuth/QR token, connection string, secret, dan PII.
- Metrik request/error/p95/startup/database health; alert health 503 tiga kali atau error >5%/5 menit.
- Retensi log demo 14 hari, hanya tim teknis.

## Keamanan

- Tidak ada fallback secret; production fail-fast.
- Seed hanya perintah eksplisit dev/test dengan credential ephemeral.
- Query wajib parameterized melalui sqlc/pgx; dilarang concatenasi SQL.
- CORS hanya `WEB_ORIGIN`; webhook nanti memakai path terpisah tanpa cookie browser.
- Dependency scan memblokir Critical/High; health tidak membuka topologi.

## Kinerja

- Catat baseline build API, bundle UI, koneksi, dan route sebelum/sesudah migrasi stack.
- Bundle client dilarang memuat connection string, env server, atau logger server.
- Health p95 ≤300 ms dan timeout database 2 detik pada preview.
- Query memilih kolom eksplisit; ukur sebelum optimasi.

## Aksesibilitas dan lokalisasi

- `<html lang="id">`, semantic HTML, skip link, focus visible, label/error, kontras WCAG 2.1 AA.
- Rupiah berupa integer dan formatter `id-ID`; tanggal menerima zona eksplisit.
- Default tampilan `Asia/Jakarta` sampai event memiliki zona; hormati reduced motion.
- Status tidak bergantung pada warna.

## Dependensi pihak ketiga/fallback

- Pin Go 1.27.1, chi/v5, pgx/v5, goose v3, sqlc CLI, Playwright untuk E2E UI.
- Jika compatibility spike gagal, hentikan rollout dan catat blocker; jangan downgrade diam-diam.
- Jika Neon gagal, hasil 503, bukan file JSON; provider lain belum dipasang.

## Kasus uji spesifik

- `F54-E2E-001`: shell pada 360 px tanpa overflow; keyboard mencapai aksi.
- `F54-E2E-002`: smoke mobile/tablet/desktop.
- `F55-UNIT-001`: 125000 menjadi `Rp125.000` tanpa pecahan (Go dan UI).
- `F55-UNIT-002`: UTC tampil dengan zona yang benar.
- `F61-UNIT-001`: env wajib hilang menghentikan startup API.
- `F61-INT-002`: dev/test/preview memakai identifier database berbeda.
- `DATA-INT-001`: database kosong termigrasi goose dan repository create/read user.
- `DATA-INT-002`: request pertama tidak menjalankan DDL/seed.
- `DATA-INT-003`: database gagal tidak membuat JSON.
- `SEC-001`: snapshot log bebas secret/password/cookie/URL DB.
- `CI-001`: gofmt/vet/test, lint UI, build API+web, E2E, scan lulus.

## Migrasi dan rollout

1. Backup branch prototype, inventarisasi user tanpa mencetak PII/hash.
2. Putuskan reset atau backfill; jalankan compatibility spike Go+UI dan pin `go.sum`.
3. Terapkan migration goose pada test memakai `DATABASE_URL_UNPOOLED`; validasi count, uniqueness, dan repository.
4. Deploy preview API+web tanpa fallback; jalankan smoke dan rollback drill.
5. Hapus runtime DDL, JSON, seed/password/secret hardcoded, ID waktu, Prisma sebagai SoT, dan raw repository lama.
6. Promote production-demo setelah CI/isolation lulus. Rollback aplikasi tetap kompatibel dengan skema additive; database dipulihkan melalui branch/backup, bukan down migration destruktif.

## Risiko dan mitigasi

- Dua proses (Go+Next.js) menambah operasional: satu reverse proxy, health terpisah, dokumentasi runbook RFC-001.
- Auth prototype NextAuth menyimpang dari target: isolasi sebagai UI lama; RFC-002 mengganti sesi ke Go.
- Data lama melanggar constraint: preflight serta backfill atau reset yang disetujui.
- Koneksi pooler Neon tidak untuk migrasi: wajib URL unpooled untuk goose.
- Secret prototype terekspos: cabut/rotasi sebelum preview.
- Scope melebar: skeleton hanya untuk kebutuhan fondasi.

## Kriteria penerimaan per fitur

### F54 — Web responsif

Shell dan komponen dasar dapat digunakan pada viewport target tanpa overflow; E2E viewport lulus.

### F55 — Bahasa Indonesia dan Rupiah

Formatter terpusat/teruji di Go dan UI; nominal integer tidak salah pembulatan dan waktu menyebut zona.

### F61 — Isolasi lingkungan

Database, secret, base URL, dan seed tiap lingkungan terpisah; startup API memvalidasinya.

## Definition of Done

1. Acceptance F54/F55/F61 dan seluruh failure path memiliki bukti test.
2. Stack target Go 1.27.1 serta presentation Next.js dipin; `go.sum` dan lockfile UI konsisten.
3. Migration goose lulus pada DB kosong dan strategi data prototype pilihan.
4. Runtime DDL/JSON/hardcoded secret-password/ID waktu/seed-on-request nol.
5. Env, logger redaction, error envelope, repository, health, UI/test/CI scaffold bekerja.
6. Format, lint, test, build API+web, E2E smoke, security scan, dan rollback drill lulus.
7. Tidak ada blocker/critical atau security Critical/High.
8. RFC-002 belum diterapkan dan hanya dimulai setelah RFC ini disetujui.
