# RFC-021 — Transisi runtime Go → Next.js (tanpa kehilangan fungsi)

| Atribut | Nilai |
|---|---|
| Status | **Aktif — keputusan Product Owner** |
| Tanggal | 23 September 2026 |
| Predecessor | RFC-001–RFC-014 (fungsional sudah berjalan di Go) |
| Tujuan | Satu proses Next.js (UI + API) di PostgreSQL/Neon yang sama, lalu Go dihapus hanya setelah paritas |

## Keputusan

Product Owner menghendaki stack **Next.js saja**. RFC-001–014 **tetap acuan fitur, invariant, error code, dan state machine**. Yang berubah hanya **tempat kode dijalankan**, bukan perilaku produk.

**Go tidak boleh dihapus** sampai checklist §5 lulus. Selama transisi, `backend/` adalah source of truth perilaku yang sudah live.

## Prinsip agar fungsi tidak hilang

1. **Strangler fig:** pindahkan per modul. UI path `/api/...` tidak berubah.
2. **Satu database:** Neon/PostgreSQL yang sama; file goose di `/migrations`; runner Node `npm run migrate` (tabel `goose_db_version` kompatibel dengan goose v3).
3. **Satu kontrak HTTP:** envelope, cookie `mti_session`, CSRF, portal, RBAC, idempotency key, integer Rupiah, invariant 1–17 di `AGENTS.md`.
4. **Default tetap Go:** rewrite Next → Go aktif sampai flag modul Next `true` dan tes modul itu hijau.
5. **Jangan dual-write** inventori/order/payment. Satu writer per use case.
6. **Hapus Go sekali** di akhir, bukan per file acak.

```text
Browser / Vercel Next.js
        │
        ├─ modul belum dipindah → rewrite ke Go :8080
        └─ modul sudah paritas  → Route Handler Next.js + Neon
```

## Fase setup (wajib berurutan)

### Fase 0 — Bekukan regresi (sekarang)

- Jangan ubah alur domain sambil porting.
- Simpan daftar endpoint Go (§6) sebagai checklist.
- Jalankan baseline: `go test ./...`, `npm test`, `npm run test:e2e` (catat yang sudah/ belum hijau).
- Lokal tetap: `go run ./cmd/api` + `npm run dev`.

### Fase 1 — Pondasi Next (tanpa memotong traffic)

Tambah folder nyata hanya saat dipakai:

```text
lib/server/db.ts              # pool Neon/pg, transaksi
lib/server/errors.ts          # envelope sama RULES.md
lib/server/auth/session.ts    # cookie mti_session (port dari Go)
lib/server/modules/<nama>/    # application + repo per modul
app/api/...                   # Route Handler; jangan dibuat sebelum modul siap
```

- Driver: `@neondatabase/serverless` atau `pg` — **bukan Prisma**.
- Validasi boundary: Zod (sudah di RULES).
- Password: bcrypt async, cost adaptif.
- Jangan daftarkan `app/api/<path>` yang menimpa rewrite Go sebelum handler Next lengkap.

### Fase 2 — Port per modul (satu PR / satu modul)

Urutan wajib mengikuti dependensi data (sama RFC lama):

1. Health / meta (`/api/health`, `/api/meta`)
2. Auth + portal + CSRF + Google (`/api/register`, `/api/auth/*`, `/api/me`)
3. Organizer application + admin decide
4. Event authoring + lifecycle + gallery
5. Catalog publik (`GET /api/events`, filters, detail)
6. Order + inventory + loyalty reservation (transaksi SERIALIZABLE / constraint yang sama)
7. Payment sandbox + webhook + refund
8. Ticket issuance + QR
9. Check-in
10. Dashboard / reporting / CSV
11. Notifications + job HTTP
12. Audit + analytics emit
13. Admin operations / search / password-reset assistance

Setiap modul:

- Salin acceptance RFC terkait, bukan “kira-kira sama”.
- Tes: unit invariant, integration PostgreSQL (checkout terakhir, double scan, idempotency), E2E alur UI yang sudah ada.
- Setelah hijau: nyalakan flag modul; matikan rewrite path itu ke Go.
- Bandingkan response JSON dengan Go (contract test).

### Fase 3 — Cutover

- Semua path §6 dilayani Next.
- Job internal (`/api/internal/jobs/*`) dipanggil scheduler ke origin Next, secret sama.
- Unggahan gallery: storage yang sama atau `public`/`uploads` via Route Handler.
- Vercel: `DATABASE_URL` + secret sesi; **tidak** butuh `API_ORIGIN` ke Go.

### Fase 4 — Hapus Go

Hanya jika §5 terpenuhi:

- Hapus `backend/` setelah SQL sudah di `/migrations` **dan** §5 lulus.
- Hapus rewrite `next.config.mjs` ke Go.
- CI: hilangkan job `go test` / `gofmt`.
- Dokumen sisa yang masih menyebut Go diperbarui di commit yang sama.

## 5. Definition of Done sebelum `backend/` dihapus

- [ ] Setiap baris §6 punya Route Handler Next dan tes.
- [ ] Invariant inventori, order, payment, loyalty, ticket, check-in lulus di PostgreSQL.
- [ ] Cookie/portal/RBAC sama.
- [ ] Katalog, dashboard pembeli/organizer/admin, checkout sandbox, wallet, scanner: E2E atau verifikasi setara.
- [ ] Tidak ada rewrite ke `:8080` di production.
- [ ] `GET /api/health` di Vercel mengembalikan JSON `ready`, bukan 500 HTML.

## 6. Inventori endpoint (harus ada di Next sebelum Go dihapus)

Auth: `POST /api/register`, `POST /api/auth/login`, `POST /api/auth/callback/credentials`, `GET /api/auth/csrf`, `GET /api/auth/session`, `POST /api/auth/signout`, `GET /api/auth/signin/google`, `GET /api/auth/callback/google`, `GET /api/auth/providers`, `GET|PATCH /api/me`, `POST /api/me/sessions/revoke`, `GET /api/users/{id}`, `GET /api/admin/ping`, reset password + bantuan admin.

Organizer/admin org: applications, capabilities, decisions.

Events: CRUD organizer, ticket types, sections, seats, seat-map, gallery upload + `/uploads/gallery/{name}`, submit/resubmit/cancel/complete/stop-sales, staff, lifecycle admin, catalog list/detail/filters/ai-filter, poster suggestions.

Orders: checkout summary, CRUD orders, loyalty account, expire-orders job.

Payments: create/get/sandbox-settle, webhooks, recon, refunds.

Tickets: list/get/qr, reconcile job.

Check-in: scanner-access, check-ins, attempts.

Lain: dashboard organizer, sales-trend, participants.csv, admin operations/search/health, recommendations, notifications + jobs, analytics emit, audit logs, smoke webhook, meta/health.

## 7. Yang tidak berubah

- Skema PostgreSQL dan invariant.
- MoSCoW, F42/F63–73 Won’t, RFC-015–020 Deferred.
- UI Bahasa Indonesia, error code Inggris.
- Larangan Prisma, NextAuth, hard-delete transaksi, uang float.

## 8. Risiko

- Port order/payment/check-in salah → overselling atau double check-in. Modul ini terakhir sebelum cutover, tes konkurensi wajib.
- `app/api` Next menimpa rewrite terlalu cepat → 404/500 di lokal dan Vercel.
- Menghapus Go lebih awal → fungsi hilang. Dilarang.
