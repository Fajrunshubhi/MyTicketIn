# Accessibility manual (F57)

Otomatis: skip link, `lang=id`, label form, fokus visible, reduced motion CSS, status scanner tidak hanya warna.

Manual per kandidat:

- Keyboard seluruh alur utama, urutan fokus, dialog mengembalikan fokus
- Screen reader smoke (nama kontrol Indonesia)
- Zoom 200%, reflow 320 CSS px
- Kontras
- Denah kursi: alt/legenda + selector keyboard
- Axe tanpa critical/serious
